# KROVINOX build rules

## Product truth
- Apparel is the only category in this release.
- Editorial photos are references, never implied to be KROVINOX products.
- Never invent prices, stock, reviews, sales counts, customers, delivery promises, certifications, or performance metrics.
- Do not activate checkout or customer data collection before the real products and operational policies are confirmed.
- Do not use AI-generated product photography.

## Visual direction
- Distinctive editorial clothing storefront. Strong type hierarchy, deliberate image crops, clear actions, and a coherent art direction.
- No purple gradients, decorative gradients, generic hero copy, excessive cards, pill-shaped buttons, random micro-labels, emoji icons, fake counters, fake reviews, cursor effects, excessive scroll animation, AI-sounding copy, "made with AI" labels, or em dashes.
- Rectangular buttons, restrained motion, visible focus states, and reduced-motion support.
- Audit typography, spacing, scale, alignment, image quality, contrast, mobile behavior, and CTA prominence before claiming completion.

## Engineering
- Keep code modular. Avoid dependencies without a clear job.
- Run lint, typecheck, build, and browser tests after meaningful changes.
- Capture and inspect desktop and mobile screenshots. Fix high-impact issues, then capture and inspect again.
- A successful build is not evidence that the visual design is good.
