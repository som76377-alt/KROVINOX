# KROVINOX

Independent clothing in development. This repository is a rebuilt apparel storefront preview. It uses real editorial photographs as references, not images of KROVINOX products for sale.

## Run locally
```sh
npm ci
npm run dev
```

## Quality checks
```sh
npm run check
```

Portable design skills are stored in `.agents/skills/`. Browser review screenshots are attached to GitHub Actions runs. Ruflo setup and prerequisites are documented in `docs/AGENT_TEAM.md`.

This is not yet an order-ready store. Prices, stock, shipping, returns, payment processing, and customer data collection must not be invented. Enable those flows only after real product and operational details are confirmed.
